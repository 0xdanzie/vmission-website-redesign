# Vedanta Mission - Brand Assets

Production package derived from the approved and locked Vedanta Mission identity board supplied with this task.

## Primary files
- `SVG/vedanta-mission-primary.svg` - primary horizontal logo for website/navigation use.
- `SVG/vedanta-mission-stacked.svg` - approved stacked institutional lockup.
- `SVG/vedanta-mission-descriptor.svg` - approved descriptor lockup.
- `SVG/vedanta-mission-emblem.svg` - approved emblem-only mark.
- `SVG/vedanta-mission-*-dark.svg` - Midnight Walnut version for light surfaces.
- `SVG/vedanta-mission-*-white.svg` - pure white version for dark surfaces.

## Favicon
Use `FAVICON/favicon.svg` as the preferred scalable favicon. PNG and ICO fallbacks are included.

## Social sharing
- `SOCIAL/og-logo-primary.png` - warm ivory Open Graph asset.
- `SOCIAL/og-logo-dark.png` - Midnight Walnut Open Graph asset.

## Website
- `WEB/vedanta-mission-navbar.svg` - primary horizontal identity.
- `WEB/vedanta-mission-footer.svg` - descriptor lockup.
- `WEB/vedanta-mission-mobile.svg` - approved emblem-only mark for constrained mobile navigation.

## Brand colors
- Bhagwa: #E06328
- Deep Gerua: #C84E17
- Sacred Ochre: #A73C0E
- Midnight Walnut: #1E1916
- Warm Temple Ivory: #FDFBF7
- White: #FFFFFF

## Usage
Prefer the Bhagwa version on light backgrounds and the white version on Midnight Walnut or other approved dark surfaces. Keep the emblem proportions unchanged. Do not stretch, skew, rotate, recolor outside the supplied palette, add effects, or recreate the ॐ separately.

## Technical note
The supplied reference was a raster identity board, not the original vector artwork or font files. The SVG masters in this package are clean path-based traces reconstructed from the approved board; no raster image is embedded in the SVGs and no external fonts are required.
